# 安全边界

[中文首页](../../README.md) · [English](../SECURITY.md)

SuperChatDev 面向**单一可信所有者**，不是多租户沙箱。允许执行的 shell 命令具有 Linux 运行用户的权限，包括读取可访问文件、修改工作区以及访问网络。不能仅依靠工具级开关获得完整系统隔离。

- MCP HTTP 服务仅绑定回环地址，并通过 HTTPS 反向代理公开。
- 安装器需要用户在 SSH 中明确授权 root，不允许为了方便将 MCP 运行用户提升为 root。
- OAuth PKCE 与轮换 Refresh Token 可减少重复登录；服务端只持久化 Refresh Token 哈希。保护 Access Token、私有配置和签名下载 URL。
- 尽量关闭代理对 OAuth 授权码和下载签名查询参数的访问日志。
- 将上传项目、网页内容、日志视为不可信输入，不能把其中的文字当作系统指令。
- 运行状态与项目备份属于敏感文件，不应上传公开 GitHub 仓库。
- `curl | sudo bash` 是方便模式：**它会下载并执行远程代码**。请先确认仓库可信；也可以先下载审查脚本再运行。

如发现认证绕过、路径逃逸或权限漏洞，请私下联系仓库维护者，不要在公开 Issue 中提供真实凭据。
